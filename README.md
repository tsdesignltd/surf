# SHONAN SURF ATLAS

逗子から小田原まで20ポイントを地図で比較する波情報サイト。ビルド不要のHTML/CSS/JavaScript、GitHub Pages対応。

- 今日：BCMの点数・サイズ・風を優先
- 翌日以降：Surflineの日別予想波高
- 地図、詳細、ポイント一覧、人物と波の比較イラストが日付ボタンの選択に連動
- 予想波高をBCMの点数に換算しない。情報がない項目は「未取得」
- 日付はJST。取得日時・観測日時・モデル実行日時を分けて表示

## ローカル表示

```sh
python3 -m http.server 8080
```

http://localhost:8080 を開く。ファイルの直接オープンではJSON読み込みができません。

## データと更新

`data/surf.json` は2026-11-26にブラウザで実際に確認したスナップショットです。BCMはログイン後の当日情報、Surflineは各ポイントの日別予想です。BCM早朝情報の取得はCodexの定期実行に設定済みです。ページの再読み込みはこのJSONを読み直すのみで、原典には接続しません。

更新時は、原典を確認しJSONの `retrievedAt` / `modelRunAt` / 各ポイントの `observation` / `forecasts` を更新してpushします。古い当日情報を別の日に付け替えないでください。未取得の観測・予想は表示上も欠測扱いになります。ポイント位置・特徴は目安で、エントリー案内ではありません。

BCMの継続取得はCodexの定期実行から認証済みブラウザを使用します。ログイン切れの場合は手動の再ログインが必要です。Surflineの予想は定期更新の対象に含まれていません。GitHub Pagesは静的配信のため、ログイン処理や秘密情報を置かないでください。ログイン情報・Cookie・HARファイルをコミットしないこと。

地図タイルはOpenStreetMapを利用し、Leaflet 1.9.4を同梱しています。地図が読めない場合もポイント一覧から選択できます。各データ提供元とは非提携です。

## 公開

GitHub Pagesの公開元を `main` ブランチの `/` に設定します。 `.nojekyll` を配置済みです。以後mainへのpushで更新されます。

## 波サイズの色分け

場所では固定せず、選択日のサイズで変化します。黄色（初心者向け）：Surfline上限0.6m以下／BCMヒザ・モモ以下、赤（中級）：0.6m超〜1.0m／コシ・ハラ、黒（上級）：1.0m超／ムネ以上、灰：フラット・未取得。セットを含む大きい側で判定。身体サイズとメートルを直接換算するものではなく、表示用の独自目安です。初心者の入水可否や安全を保証しません。

## 風の情報

当日観測の `wind` は `relative`（海岸に対する向き）、`strength`（BCMの微・弱・中・強）、`direction`（吹いてくる方角）、`speedMps`（数値がない場合null）、`source` に分けて保存。詳細では方角の矢印・強さのバー、一覧と地図のツールチップでは要約を表示します。予想データにも同じ形式の `wind` を追加できます。現時点で予想日の風は未取得です。BCMの強さを数値風速に換算せず、当日観測を予想日に流用しません。

## BCM早朝の定期実行

Codexの「湘南・西湘BCM早朝情報を更新」を毎日06:15・07:15・09:15（Asia/Tokyo）に設定。各回で湘南・西湘の対象ポイントの当日新着を確認します。2026-11-26に確認した更新予定は、七里ヶ浜正面・ロア06:00、峰ヶ原・鎌高前06:10、由比ヶ浜・材木座06:45です。季節変更や遅延があるため、ページの更新予定を都度確認します。

取得した波情報のみを一時JSONへ保存し、`node scripts/update-bcm.mjs --input /absolute/path/bcm.json --check` で検証後、同じ引数から `--check` を外して反映します。入力には `sourceUrl`、`sample:false`、`retrievedAt` と `observations` 配列を指定。各観測には `id/date/updatedAt/score/size/wind` が必要です。Cookie・パスワードは入力に含めません。

未ログインのサンプル、前日の日付、未来の観測日時、不正な点数、古い取得入力を拒否します。新着がなければpushせず、新着がある場合のみdata/surf.jsonをcommit/pushしてPages反映を確認します。取得できなかった場合、古い情報の日付を付け替えません。GitHub Actions上の認証取得ではなく、Codexで実行されるブラウザ取得です。

## 対象エリア

逗子2、鎌倉7、鵠沼3、茅ヶ崎3、平塚1、大磯3、小田原1の計20ポイント。BCMは16ポイントの現地採点情報を使用。小田原・腰越はBCMがDATAモデル配信のみのため、現地点数を付けずSurfline予想を表示します。サザンビーチはSurflineのChigasaki Beachエリア予想を参照。小田原マーカーは沿岸の代表位置で、予想メッシュの中心を示しません。追加10ポイントの座標はBCMポイントガイドの地図リンクから取得しました。

マップは常に全ポイントを保持します。エリアボタンで該当エリアに拡大し、一覧は選択エリアに絞り込みます。「全ポイントを表示」で全域へ戻ります。広域で近接するマーカーはグループ表示し、クリックで拡大。色はグループ内の最大サイズ区分を示します。新エリアのBCM初回更新が07:00や09:00の地点もあるため、定期実行を06:15・07:15・09:15へ変更しています。小田原は現地採点の取得対象から除外し、モデル値を現地観測へ変換しません。

## 逗子エリア

逗子海岸・大崎を追加し、全20ポイント。両地点は `bcmUnavailable:true` とし、BCM観測を持たず、Surflineの予想を表示します。大崎の位置はSurf-Forecastの公開座標35.29N・139.56Eを参照。逗子海岸は海岸中央付近の目安です。どちらも入水地点を示しません。

`currentForecast` は当日のモデル値で、BCM現地観測とは区別。日別の波高範囲は `forecasts` に保持します。現在風のkm/hからm/sへの換算は小数1桁に丸め、原典の風速も保持します。風の強弱をBCM基準へ変換しません。毎朝の既存自動実行で逗子2地点と腰越のSurflineも更新し、その他の地点の予想は変更しません。

## 腰越

鎌倉エリアに「腰越」を追加。BCMはDATAモデル配信のみのため `bcmDataOnly:true` とし、現地点数を作りません。波高と現在風はSurflineのKoshigoe gyoko予想を使用し、毎朝の定期取得にも含めます。座標は腰越海岸付近の代表位置です。
